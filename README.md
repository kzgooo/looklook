# 隧道技术学习靶场

> 一个用于学习 SSH 隧道、内网穿透与提权技术的简易 Docker 靶场环境。

---

## 一、项目简介

本项目旨在帮助学习者熟悉**隧道技术（SSH Tunneling）**，通过构建一个多层级的内网环境，模拟真实渗透测试场景中的网络拓扑。

通过此项目，你可以学习到：

- SSH 本地转发 / 远程转发 / 动态转发（SOCKS 代理）
- 内网穿透与多层跳板
- Linux 提权基本操作
- Docker 网络隔离与自定义网络构建

## 二、网络拓扑

```
                    ┌─────────────┐
                    │  电脑 A     │
                    │ (攻击机)    │
                    └──────┬──────┘
                           │ 出网
                           │
                    ┌──────▼──────┐
                    │  电脑 B     │
                    │ (Web服务器) │
                    │   出网      │
                    └──┬───────┬──┘
                       │       │
              ┌────────▼──┐  ┌─▼────────┐
              │  电脑 C   │  │ 电脑 D   │
              │  不出网   │  │  出网    │
              └─────┬─────┘  └──────────┘
                    │
              ┌─────▼─────┐
              │  电脑 F   │
              │ 与 C 互通 │
              └───────────┘
```

### 各节点说明

| 节点 | 角色 | 网络特性 | 说明 |
|------|------|----------|------|
| **A** | 攻击机 | 出网 | 你自己操作的主机 |
| **B** | Web 服务器 | 出网 | 入口点，可被 A 访问 |
| **C** | 内网主机 | 不出网 | 与 B 互通，与 D 不互通，与 F 互通 |
| **D** | 内网主机 | 出网 | 与 B 互通，与 C 不互通，**需要提权** |
| **F** | 内网主机 | 不出网 | 仅与 C 互通 |

### 关键约束

- **C 与 D 不互通**
- **C 不出网，D 出网**
- **F 只能通过 C 访问**
- 目标是使用 A 控制 **C、F、D**（D 需要提权）

## 四、一键管理脚本

```bash
usage() {
    echo "用法: $0 {start|reset|status|stop|down}"
    echo "  start   一键启动靶场(容器存在则直接启动, 不存在则创建)"
    echo "  reset   一键重置靶场(删除全部容器与网络, 重建初始环境)"
    echo "  status  查看靶场运行状态"
    echo "  stop    停止全部容器"
    echo "  down    停止并删除全部容器与网络"
}
```

### 命令说明

| 命令 | 功能 | 使用场景 |
|------|------|----------|
| `start` | 一键启动靶场（容器存在则直接启动，不存在则创建） | 首次启动或日常使用 |
| `reset` | 一键重置靶场（删除全部容器与网络，重建初始环境） | 环境被破坏，需要还原 |
| `status` | 查看靶场运行状态 | 检查容器是否正常运行 |
| `stop` | 停止全部容器 | 暂时关闭环境，保留数据 |
| `down` | 停止并删除全部容器与网络 | 完全清理环境 |

### 使用方法

```bash
# 添加可执行权限
chmod +x manage.sh

# 启动靶场
./manage.sh start

# 查看状态
./manage.sh status

# 重置环境
./manage.sh reset

# 停止容器
./manage.sh stop

# 销毁环境
./manage.sh down
```

## 五、快速开始

### 1. 环境要求

- Docker 20.10+
- Docker Compose 2.0+
- Linux / macOS（Windows 需 WSL2）

### 2. 启动靶场

```bash
git clone <本项目地址>
cd tunnel-lab
chmod +x manage.sh
./manage.sh start
```

### 3. 查看状态

```bash
./manage.sh status
```

### 4. 开始学习

从 A 主机访问 B 的 Web 服务，逐步向内网渗透，利用 SSH 隧道打通 C、D、F 的网络隔离。

## 六、学习目标与路线

### 阶段一：信息收集

- 扫描 B 的开放端口，发现 Web 服务与 SSH 服务
- 通过 Web 漏洞 / 弱口令获取 B 的 Shell

### 阶段二：建立隧道

- 以 B 为跳板，使用 SSH 动态转发（`-D`）建立 SOCKS 代理
- 通过代理扫描内网，发现 C、D

### 阶段三：横向移动

- 通过 B 访问 C，建立本地 / 远程转发
- 借助 C 访问 F（C 与 F 互通）
- 由于 C 与 D 不互通，需要通过 B 访问 D

### 阶段四：提权

- 对 D 主机进行信息收集
- 利用 SUID / 内核漏洞 / 计划任务等方式提权至 root

### 阶段五：多层隧道

- 组合使用本地转发 + 远程转发 + 动态转发
- 打通 A → B → C → F 的完整链路

## 七、常用 SSH 隧道命令速查

### 本地转发（Local Forward）

```bash
ssh -L <本地端口>:<目标IP>:<目标端口> user@跳板机
```

### 远程转发（Remote Forward）

```bash
ssh -R <远程端口>:<目标IP>:<目标端口> user@跳板机
```

### 动态转发（SOCKS 代理）

```bash
ssh -D <本地端口> user@跳板机
```

### 多层跳板

```bash
ssh -J user1@host1,user2@host2 user3@host3
```

### 配合 proxychains

```bash
proxychains4 nmap -sT -Pn <内网IP>
```
